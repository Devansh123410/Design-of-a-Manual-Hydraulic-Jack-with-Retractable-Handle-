## 📋 Project Summary
This repository contains the complete industrial project design, operational planning, structural drawings, and cost estimations for establishing a small-scale manufacturing facility in Aligarh. The core engineering innovation focuses on a modified manual floor jack integrated with a **retractable handle mechanism** and a **torsional spring return assembly** designed to minimize mechanical strain, speed up operation cycles, and optimize storage parameters within workshop spaces.

## 🛠️ Engineering Features & Specifications
* **Innovative Return System:** Utilizes a custom carbon steel torsional spring to automatically reset the pump handle position, eliminating redundant dual-stroke physical exertion.
* **Retractable Ergonomics:** Space-saving handle layout optimizes portability and storage configurations without degrading industrial loading performance.
* **Industrial Utility Planning:** Multi-criteria screening matrix used for site validation, infrastructure capacity modeling, and workspace ergonomics.

## 📐 Industrial Operations Covered
1. **Market Survey & Demand Analysis:** Competitive strategy evaluations, channel analysis, and pricing determinants.
2. **Plant Site Selection:** Multi-criteria filtering justifying establishment within the industrial zones of Aligarh.
3. **Workspace Design:** Detailed floor layout optimization spanning the operating shop floor, storage bays, utilities, and emergency transit pathways.
4. **Operations & Process Planning:** Machining sequence blueprints across turning, drilling, cutting, and spring assembly cycles.
